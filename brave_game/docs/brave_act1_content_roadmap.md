# Brave Act 1 Content Roadmap

## Purpose

This roadmap turns `docs/brave_act1_agent_bible.md` into a practical production sequence for Creator API content runs. It is not a lore bible and not a technical API contract. It answers what to build next, in what order, and why.

The default workflow is draft-first: each batch should become one Creator API Agent Run, pass validation and previews, appear in Creator Studio for review, and publish only after review.

## Area Source Docs

Use these area bibles as the creative brief for Creator API runs:

- `brave_act1_goblin_road_area_bible.md`
- `brave_act1_whispering_woods_area_bible.md`
- `brave_act1_old_barrow_field_area_bible.md`
- `brave_act1_ruined_watchtower_area_bible.md`
- `brave_act1_goblin_warrens_area_bible.md`
- `brave_act1_blackfen_drowned_weir_area_bible.md`

When a roadmap batch touches one of these areas, the area bible wins for tone, allowed content, avoid rules, and preferred quest concept. The broader Act 1 bible still wins for act-level canon and constraints.

## Production Goals

- Strengthen Act 1 without expanding beyond its current Brambleford-centered crisis.
- Add playable texture around existing regions instead of creating disconnected new areas.
- Improve NPC reactivity after major quest beats.
- Reduce future generated-content risk by using small, reviewable batches.
- Avoid adding new bosses unless explicitly called out.

## Batch 1: Brambleford Post-Alarm Civic Follow-Ups

Intent: make Brambleford feel more reactive after the opening alarm and early errands.

Anchor content:

- `practice_makes_heroes`
- `bell_before_the_road`
- `rats_in_the_kettle`
- Captain Harl Rowan, Brother Alden, Mayor Elric Thorne, Sister Maybelle, Mistress Elira Thorne

Recommended Creator API scope:

- `dialogue`: add active/completed lines for early quest states.
- `item`: add one modest town keepsake or emergency supply item.
- `quest`: optional small side quest tied to town supplies or chapel morale.

Acceptance target:

- One early-town side quest or dialogue pack that makes Brambleford acknowledge the player's first useful work.
- No new rooms.
- No new enemies unless the side quest directly uses the inn cellar or Wayfarer's Yard.

## Batch 2: Goblin Road Repair Thread

Intent: add a grounded side thread about repairing or documenting the damage caused by goblin fence-cutters.

Anchor content:

- `roadside_howls`
- `fencebreakers`
- `ruk_the_fence_cutter`
- East Gate, Old Fence Line, Fencebreaker Camp

Recommended Creator API scope:

- `quest`: one repair/scout/proof quest.
- `item`: road repair token, cut rail mark, or field ledger.
- `dialogue`: Captain Harl or Mayor Elric reaction.
- `encounters`: optional encounter update using existing goblin or wolf enemies.

Acceptance target:

- The road feels like infrastructure Brambleford must restore, not just a combat corridor.
- Rewards are practical and modest.
- Ruk remains the local capstone.

## Batch 3: Whispering Woods Wardstone Enrichment

Intent: deepen the old-stone unease without turning the woods into a separate fae campaign.

Anchor content:

- `what_whispers_in_the_wood`
- `herbs_for_sister_maybelle`
- `greymaws_trail`
- Old Stone Path, Briar Glade, woods wardstone

Recommended Creator API scope:

- `read`: add or refine a wardstone/readable clue.
- `quest`: one short side quest about confirming, restoring, or carrying a ward mark.
- `item`: ward chalk, moonleaf bundle, or old path token.
- `dialogue`: Sister Maybelle or Mira Fenleaf.

Acceptance target:

- The woods point more clearly toward the barrow field.
- Any new item has quest use or readable context.
- No new major faction.

## Batch 4: Old Barrow Chapel and Marker Names

Intent: make the chapel/barrow chain more personal by tying grave markers and names back to Brother Alden.

Anchor content:

- `lanterns_at_dusk`
- `do_not_disturb_the_dead`
- `the_knight_without_rest`
- Chapel of the Dawn Bell, Marker Row, Barrow Circle, Sunken Dais

Recommended Creator API scope:

- `quest`: one name/proof/recovery side quest.
- `read`: marker text or chapel record.
- `item`: votive, recovered name strip, grave token, or small story proof.
- `dialogue`: Brother Alden active/completed lines.

Acceptance target:

- The undead remain failed rest and old duty, not generic necromancy.
- The quest adds emotional weight before or after Sir Edric.
- No second fallen-knight boss.

## Batch 5: Ruined Watchtower Prisoner or Scout Thread

Intent: show how human opportunists exploit the wider crisis.

Anchor content:

- `smoke_on_the_ridge`
- `loose_arrows`
- `captain_varn_blackreed`
- Watchtower Approach, Archer's Ledge, Breach Yard, Blackreed's Roost

Recommended Creator API scope:

- `quest`: one prisoner, scout, stolen-ledger, or signal-mark side quest.
- `item`: blackreed ledger, road tally, snapped signal arrow, or watch token.
- `dialogue`: Captain Harl or Mayor Elric.
- `encounters`: optional bandit composition using existing enemies.

Acceptance target:

- The tower reads as a repurposed border structure.
- Blackreed stays a regional human commander, not a national faction.
- New content clarifies road control or exploitation.

## Batch 6: Goblin Warrens Logistics Thread

Intent: make the warrens feel organized by hunger, theft, and crude domestic systems.

Anchor content:

- `below_the_fencebreakers`
- `gutters_and_hexes`
- `the_pot_kings_feast`
- Sinkmouth Cut, Torchgut Tunnel, Bone Midden, Feast Hall

Recommended Creator API scope:

- `quest`: one stolen food, tunnel cleanup, crude recipe, or prisoner scrap side quest.
- `item`: grease-stained note, stolen stores, pot token, hex-scrap, or cooking/crafting hook.
- `dialogue`: Mistress Elira, Uncle Pib, or Harl.
- `encounters`: optional use of existing goblin/hexer/bat/slime enemies.

Acceptance target:

- The warrens feel gross, functional, and local.
- Grubnak remains the capstone.
- New loot has placement or use.

## Batch 7: Blackfen Survey and Field Notes

Intent: connect Blackfen's predators and boglights to Brambleford's need to map the south route.

Anchor content:

- `bogwater_rumors`
- `lights_in_the_reeds`
- `miretooths_claim`
- Fenreach Track, Reedflats, Carrion Rise, Boglight Hollow

Recommended Creator API scope:

- `quest`: one survey marker or field-note recovery quest.
- `item`: marsh survey tag, silt hook, fen resin, jaw-score tracing, or reed map.
- `dialogue`: Mira Fenleaf or Joss Veller.
- `encounters`: optional Blackfen encounter variation using existing enemies.

Acceptance target:

- The marsh remains physical and hungry, not purely spectral.
- The quest points toward Drowned Weir without explaining it fully.
- Miretooth remains the apex predator.

## Batch 8: Drowned Weir Technical Payoff

Intent: strengthen the transition from Blackfen danger to the old road-light system.

Anchor content:

- `bridgework_for_joss`
- `signal_in_the_scrap`
- `foreman_coilback`
- `the_south_light`
- Lower Lanternworks, Sunken Lock, Blackwater Lamp House

Recommended Creator API scope:

- `quest`: one maintenance-map, lensglass, or ward-clamp support quest.
- `item`: lens shard, stamped clamp, blackwater keymark, road-light ledger, or signal scrap.
- `dialogue`: Joss Veller, Mender Veska Flint, Mayor Elric.
- `encounters`: optional weir construct or warder placement using existing enemies.

Acceptance target:

- The road-light system becomes easier to understand as civic infrastructure.
- The Hollow Lantern remains the Act 1 capstone.
- No full cosmology reveal.

## Batch 9: Trophy Hall and Capstone Reactions

Intent: make regional victories visible and emotionally recognized in Brambleford.

Anchor content:

- Trophy Hall
- Trophy hooks for Blackreed, Blackwater Beacon Core, Hollow Lantern Prism, Miretooth, Pot-King
- Major completed quests across Act 1

Recommended Creator API scope:

- `dialogue`: completed-state lines for Harl, Elric, Joss, Alden, Maybelle, Mira, Elira, or Pib.
- `read`: trophy labels or display text if needed.
- `systems`: trophy text updates only if existing hooks need refinement.

Acceptance target:

- Completing major threats changes how town anchors speak.
- Trophy text reinforces proof and memory.
- No new quest required unless a trophy handoff is missing.

## Batch 10: Readable Cleanup and Town Texture

Intent: reduce readiness warnings and make existing readable entities useful.

Anchor content:

- Existing readable entities without text.
- Town notice board, tutorial boards, kitchen hearth, loaner rack, trophy vitrine.

Recommended Creator API scope:

- `read`: add concise readable passages.
- `dialogue`: only if a readable points to an NPC.

Acceptance target:

- Existing unread readables gain useful text.
- Text gives one concrete clue, instruction, or town detail.
- No new quest or item unless the readable explicitly sets up a later batch.

## Batch 11: Orphan Item Placement Pass

Intent: reduce readiness warnings by connecting useful existing items to quests, loot, systems, or readable context.

Anchor content:

- Current readiness warnings for orphaned items such as `lantern_pixel_pin` and `weirglass_eel`.

Recommended Creator API scope:

- `quest`: use an orphan item as a reward or collection target.
- `encounters`: add it to appropriate enemy loot if it is a material.
- `systems`: connect it to cooking, fishing, forge, tinkering, or trophy logic if appropriate.
- `dialogue` or `read`: add context only when it does not create another orphan.

Acceptance target:

- Fewer orphan item warnings.
- No new orphan items.
- Item placement fits Act 1 region logic.

## Batch 12: Encounter Polish Pass

Intent: reduce unused enemy/readiness warnings and add encounter variety where a region feels thin.

Anchor content:

- Current readiness warning for unused enemy `salvage_drone`.
- Existing Drowned Weir construct identity.

Recommended Creator API scope:

- `encounters`: add or revise room encounter composition.
- `dialogue` or `read`: optional field note explaining the enemy's local purpose.

Acceptance target:

- Every newly touched enemy has a room encounter or roaming role.
- Encounter intros are concrete and immediate.
- No new enemy templates unless the batch explicitly needs them.

## Recommended Order

Start with low-risk, high-context batches:

1. Brambleford Post-Alarm Civic Follow-Ups
2. Readable Cleanup and Town Texture
3. Goblin Road Repair Thread
4. Whispering Woods Wardstone Enrichment
5. Old Barrow Chapel and Marker Names

Then move into region enrichment:

6. Ruined Watchtower Prisoner or Scout Thread
7. Goblin Warrens Logistics Thread
8. Blackfen Survey and Field Notes
9. Drowned Weir Technical Payoff

Then polish the full Act 1 surface:

10. Trophy Hall and Capstone Reactions
11. Orphan Item Placement Pass
12. Encounter Polish Pass

## Creator Run Prompt Template

```text
Use docs/brave_act1_agent_bible.md, docs/brave_act1_content_roadmap.md, and docs/creator_agent_contract.md.
Create one Creator API Agent Run for roadmap Batch [number]: [batch name].
Treat existing live content as canon.
Write draft mutations only.
Use existing rooms unless the batch explicitly calls for new rooms.
Do not add a new boss.
Include previews for every touched quest, item, dialogue target, enemy, encounter room, read target, trophy, or system hook.
Run validate, dry-run, apply, and verify.
Stop for Creator Studio review before publish.
```

## Done Criteria for Each Batch

- Agent Run exists and has a clear instruction summary.
- Run validation passes before draft writes.
- Dry-run diffs are inspected for unexpected unrelated changes.
- Draft apply succeeds.
- Verify includes previews for all touched content.
- Draft health has no validation errors.
- Creator Studio review notes explain what was checked.
- Publish happens only after human review or explicit instruction.
